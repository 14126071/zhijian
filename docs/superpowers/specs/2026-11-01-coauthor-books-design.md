# 纸间 · 对话写书与专题创作

日期：2026-11-01。状态：已由用户继续指定第一部作品与“原理与动手各半”的方向推进；技能、模块与首版书稿已实现。

## 目标

在现有“纸间”内增加独立的“写书与专题”模块，以及可跨对话使用的 `coauthor-books`（对话写书）技能。用户可以只带着问题、想法、经历或零散文字开始，不要求 PDF。通过聊天积累材料、形成结构、写作和修订；网站呈现保存的图文作品。

沿用暖纸色、墨蓝、中文衬线与现有阅读体验。读书档案继续使用 `distill-books`，创作作品由新技能维护。

## 方案选择

1. **推荐：独立创作目录，复用网站阅读组件。** 创作来源、进度与章节语义独立；继续使用现有目录、图片放大、收藏和阅读位置功能。需要适度扩展构建器与阅读器。
2. 全部放进 `books/`，添加类型字段。改动较少，但写作状态与“已读页码”等语义容易混用。
3. 单独建设写作网站。隔离充分，但重复维护网站、风格和阅读功能，当前没有必要。

采用方案一。此次不加入浏览器编辑器、在线聊天、账号系统或自动发布流程。

## 新技能

安装位置：`/Users/billson/.codex/skills/coauthor-books/SKILL.md`。以 `references/project-format.md` 说明创作文件契约。更新项目 `AGENTS.md`，让新对话可以找到该技能。

触发范围：用户要共同写书、口述成章、持续组织专题、整理创作材料、调整目录或修订已有作品。普通读书笔记仍归 `distill-books`；简单的一次性润色不强制创建作品。

工作方式：

- 先看现有作品与写作记录，识别是新作、续写、专题补充还是局部修订。
- 开始时用少量对话了解中心问题、读者和表达目的；信息不足时每轮优先追问最关键的一点。允许先整理片段，再形成目录，不要求用户一次交出完整设定。
- 对尚不成熟的想法先形成可讨论的结构或短段落，不默认一次生成整本书。用户指定整章或更大范围时按其要求执行。
- 以用户的观点与声音为主；区分用户表达、助手建议、外部证据和待核实信息。不得将助手拟写的个人经历或立场归到用户名下。
- 写作中可用结构图、关系图和时间线解释问题；图有明确用途时再制作，不要求每章固定配图。
- 每轮将有价值的内容写入对应作品，记录已确定的方向、开放问题与下一步；跨对话靠文件接续，不依赖聊天隐含记忆。
- 用户要求整理成章或保存的正文可作为草稿展示；随口讨论进入素材记录。明确区分构思、草稿、修订中、定稿，只有用户认可定稿时才标为定稿。
- 修改保留作品、章节和 block ID，保留用户自己的表述与决定；局部修改不覆盖整部作品。
- 不要求不存在的 PDF；需要外部事实时查证并记录真实出处，不编造引用。用户后续提供 PDF 时按所需范围取材。

## 文件契约

```text
writings/<work-id>/
  work.json               # 作品元数据、类型、进度、章节清单
  project.md              # 已确定的目的、读者、声音、结构与写作决定
  workshop.md             # 素材、讨论摘要、开放问题、下一步
  chapters/<chapter>.md   # 网页展示的图文正文
  assets/                 # 正文图解与图片
```

`work.json` 包含稳定 `id`、`title`、`kind`（book 或 topic）、`description`、`status`、`writing_progress`、有序 `chapters`。作者仅在用户指定后填写，不推测署名。章节记录稳定 `id`、文件路径、标题、摘要、状态与版本；未落笔的目录项允许没有文件，不生成虚构正文或可点击的空章节。

章节继续使用 Markdown frontmatter、`updated` 日期及 `<!-- block: stable-id -->` 模块；来源说明使用真实聊天日期、用户材料或外部资料，不伪造 PDF 页码。正文和元数据的状态、版本同步。

只有列入章节清单且有正文的章节及其资源参与网页构建；`project.md` 和 `workshop.md` 保持本地，不进入网站生成物。生成的 `content.json` 仅保留展示需要的字段。原始附件与临时文件不进入网站。

## 网页行为

- 侧栏增加“写书与专题”，路由 `#/writing`，显示真实作品数量；原有“我的书架”继续只列共读书籍。
- 模块展示作品类型、简介、写作进度、章节与状态，并提供进入正文的链接。无作品时显示简洁说明：在聊天里提出想写的主题即可开始。没有产生内容时不创建示例作品。
- 创作章节采用 `#/write/<chapter-id>` 与可选 block 后缀；既有 `#/read/` 链接保持有效。
- 复用阅读排版、图解放大、字号、收藏与位置记忆。创作正文的面包屑返回创作模块，展示“本章材料与说明”“作品目录”等写作语义，不出现“原书”“PDF页码”或“已读范围”的错误默认值。
- 搜索与收藏同时支持读书笔记与创作章节，并标明所属作品；“阅读足迹”保持读书范围，创作进度在创作模块显示。
- 手机导航、空目录与仅有规划尚无正文的作品应能正常打开。
